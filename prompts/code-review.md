# プロンプト: コードレビュー

BuildOne Framework の変更をレビューしてください。次の観点で、重大度順に指摘してください。

## 観点

- **設計整合**: `docs/architecture.md` の軽量 Feature First に沿っているか。Coreに業務ロジックが混入していないか。過剰設計（不要なRepository/DTO/層分割）がないか。
- **正しさ**: バグ・境界条件・N+1・例外処理。
- **セキュリティ**: `docs/security.md` 準拠（秘密情報の非コミット、認可、入力検証、CSRF、ログにパスワードを出さない、Blade自動エスケープ）。
- **UI/アクセシビリティ**: UI Kit の再利用、`aria`/フォーカス/コントラスト、モバイル対応、外部JS非依存。
- **テスト**: 主要経路と失敗系がテストされているか。
- **品質ゲート**: `composer ci`（Pint / PHPStan lv6 / Pest）が緑か。
- **簡潔さ**: 重複、命名、Fat Controller、不要な複雑さ。

## 出力

- 各指摘に「ファイル:行」「なぜ問題か」「修正案」を付ける。
- 確信度が低いものはその旨を明記。憶測を断定で書かない。
